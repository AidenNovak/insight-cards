# 试用用的原始笔记

未经整理，保持作者随手记下的样子。

1. 我发现自己每次说要"重新开始"的时候，做的都是同一件事：换一个地方，然后把同样的习惯带过去。三年里换了四个城市。困惑的内容几乎没变过。

2. 大概有两年时间，我每天记很多东西，但从来不看。后来有一次我被迫整理，发现真正有用的是五条，而且那五条当时记的时候我完全没觉得它们重要。

3. 我一直以为我是慢慢变好的。但回头看几个明显的转折点，每一次都是在很短的时间里发生的，前后是长长的什么都没发生的时期。

4. 有个人跟我说了一句话，我当时觉得他是随口说的。三年后我在一个完全不相关的场合突然想起那句话，然后发现它一直在影响我的判断。

5. 我不是被那些我认真读过的书改变的，是被我反复读的那几本改变的。而且反复读的原因往往不是因为它重要，是因为读起来舒服。

6. 我身上有一些反复出现的模式：总是在同一种人身上受挫，总是在快要完成的时候拖延。我一直把它们当成不同的缺点分别处理，处理了很多年。

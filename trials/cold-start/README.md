# 冷启动试用

这六张卡是**另一个 agent 在完全没有上下文的情况下**做的：只给它六条未整理的原始笔记，
和这份技能自身的文档（SKILL.md + references/），不给任何提示。

目的是检验**文档能不能教会一个陌生人用这套东西**——
包括最关键的"怎么选主题"（按机制配对，不是按题材相似）。

笔记的原文见本目录的 NOTES.md。

## 它选出来的配对

| 笔记 | 主题 | 机制 | 配色 |
|---|---|---|---|
| 1 每次"重新开始"都在做同一件事 | startrails | 轴心 | deep-field |
| 2 记了很多但从不看 | starfield | 注视 | abyss |
| 3 转折其实发生得很短 | discharge | 击穿 | core |
| 4 一句话三年后才起作用 | echo | 延迟 | amber |
| 5 改变我的是反复读的书 | tideline | 累积 | brass |
| 6 五个缺点其实是同一个 | lattice | 结晶 | graphite |

**注意它没有按题材表面相似去选。** 比如第 6 条讲的是"缺点"，
按题材该配个"迷宫""岔路"之类；它配了**晶格**（结晶），
因为那句话的机制是"成分没变，变的是排列"——这正是文档里教的方法。

第 5 条配**潮痕**（累积）也是同理：反复读同一本书 = 同一条痕被反复刻。

## 这次试用暴露出的问题（都已修）

试用者在完全没有上下文的情况下做这套卡，暴露了七处真问题。
按严重程度排：

| 问题 | 后果 | 修法 |
|---|---|---|
| 每张卡启停一次浏览器 | `readability` 跑到 200 多张就资源耗尽中断，全量模式根本跑不完 | `renderCard` 支持复用浏览器，全程一个；现在本机也能跑完 648 张 |
| `Tools/` 与 `registry/` 没被安装 | SKILL.md 里的远程构建整节不可用、`dbg-theme.mjs` 不存在、`gallery.mjs` 生成空页 | 安装脚本补上这两个目录 |
| `gallery.mjs` 按 cwd 找 `registry/` | 从任何别的目录调用都生成**空页，且不报错** | 路径锚定到项目根目录；空页时非零退出并出声 |
| 机制表手抄、会漂 | 两张表行序不一致，写"十四种"时实际已有十八种 | 表由 `bin/gen-tables.mjs` 从主题文件生成，`doc-check` 会查 |
| "放电"既是主题名又是机制名 | 试用者把 `discharge` 的机制误读成"放电"（它是"击穿"） | `synapse` 的机制改名"激发" |
| `--themes` 不打印 `note` | 而 `note` 正是从外部选主题最需要的一句；试用者只能一个个去 head 文件 | 加 `--themes --full` |
| 帮助文本与文档不一致 | 写了不存在的 `--deck`；`--kicker`/`--footer` 能用却没列 | 修正，并加 `bin/doc-check.mjs` 长期守着 |

另外两处判据补充：`palette-check` 之前不在 SKILL.md 的校验清单里（试用者自己发现的，
而它恰好是排 deck 最需要的）；`readability` 之前只能用内置文案，不能体检用户自己的句子。

## 这件事本身说明了什么

**文档的漏洞要靠陌生人才能发现。** 我在这份文档上已经迭代了很多轮，
但每一条真正的问题——包括那个让全量体检跑不完的资源泄漏——都是
一个不知道背景的 agent 按文档做事时撞出来的。

所以这份 README 保留在这里，不是为了展示产物，是为了留下**试用记录**：
下次改这份技能之后，值得再找一个人冷启动跑一遍。

## 第二次核验

第一次试用之后，我又请了一个**独立 agent**（同样没有上下文）
去**证伪**我自己的说法，而不是确认。它发现了几处真缺陷，
也让我逮到自己差点发出去一个假检查。经过记在
[`VERIFICATION-2.md`](VERIFICATION-2.md) 里 —— 那一份更值得读，
因为里面两次都是"我以为对、实际错"。

另外它顺手撞上一件事：核验期间它看到 `echo.mjs` 变成了 `strata` 的代码，
报了"仓库被另一个 agent 改坏了"。**那其实是我自己做的破坏性实验的残留**，
当时我正在测"主题画错东西时检查会不会响"。虚惊一场，
但也说明这种实验必须立刻还原（后来确认逐字节还原了）。

## 一个提醒

`NOTES.md` 里是**真实的人写的、未经整理的私人笔记**，六张卡都是照它们做的。
留在这里是因为"输入是什么、产出是什么"必须能对照着看，否则这份记录没有意义。

但它意味着：**这个目录里的内容不适合直接公开**。仓库要推出去之前，
把 `trials/` 换成脱敏的示例，或者先确认写这些字的人同意公开。
（图片里也印着这些文字，所以藏起 NOTES.md 不够。）
